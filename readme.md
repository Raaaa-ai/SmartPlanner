# SmartPlanner

本地优先的 Windows 个人工作台（Electron + React + TypeScript）。

## 功能

- 今日总览、待办、项目与月历
- 课程表：本周课表支持一门课多个不连续时间段、删除课程、完整显示课程名、自动压缩无课时间段
- 选课计划：未来学期表格化展示，冲突课程在同一时段上下排列；下方提供手动登记的学分类别表
- 桌面便签：可选地把待办、项目、打卡、课程放到窄便签中，固定在 Windows 桌面图标上层，不置顶；显示桌面时仍然保留
- 便签内可直接新增、修改、删除；详细字段通过完整编辑窗口填写，并与工作台实时同步
- 打卡：自定义目标天数，默认按月统计，支持补打和取消
- 纪念日：支持阳历和阴历，可按年重复或仅一次
- 今日页显示今日课表与今日打卡
- 记录卡、每日感想、笔记与快速记录
- 一键清理已完成待办、历史每日感悟、已过期的一次性纪念日
- 离线激活：激活码与电脑机器码绑定，无需账号和登录

## 运行

```bash
npm install
npm run dev
```

- 按 `Ctrl + Alt + Space` 呼出快速记录
- 关闭主窗口后应用仍在系统托盘运行
- 右上角图钉用于固定窗口位置，固定后无法拖动，再次点击解除
- 侧栏可收起为图标模式
- 桌面便签是可选功能：在「设置 → 桌面便签」选择模块并点击「打开便签」；关闭便签后不会自动出现，保持打开时下次启动会恢复
- 便签使用 Windows WorkerW 挂到桌面层，不是置顶窗口；关闭工作台窗口时，只要便签还开着，应用会留在托盘，便签继续显示
- 如果系统不支持 WorkerW，便签会提示并退回普通窗口，可点击便签上的状态按钮重试
- 便签内可以直接添加、修改、删除待办、项目和打卡；课程通过便签上的「管理」打开课程表编辑
- 修改代码后请先从托盘菜单「退出」旧实例，再重新运行，否则会看到旧界面
- 托盘菜单可打开工作台、快速记录、检查更新或退出

## 授权

- 首次启动会显示本机机器码；把机器码发给软件提供者，换取专属激活码
- 激活码只对当前电脑有效，无需联网，也没有账号或登录
- 重装 Windows 或更换主要硬件后机器码会变化，需要重新签发
- 签发工具位于 `scripts/`，私钥保存在仓库外的用户目录，请自行备份
- Windows 双击 `scripts/issue-license.bat` 会通过 WSL 调用 Node；也可以在 WSL 中直接运行 `node scripts/issue-license.mjs "机器码" "备注"`
- 纯本地校验可以阻止安装包被随意转发使用，但无法防止逆向修改程序

## 数据

- 默认数据目录：优先 `D:\SmartPlanner_data`，否则 `%APPDATA%\smartplanner\data`
- 数据目录不存在时会自动创建；创建失败会自动回退到 `%APPDATA%\smartplanner\data`
- 数据目录与安装目录分离，更新或卸载安装目录不会影响数据
- 旧版数据若在 `D:\SmartPlanner\data`，启动时会自动复制到安全目录，原目录保留
- 主数据文件：`smartplanner.json`；每日自动备份保存在数据目录下的 `backups`，保留最近 20 份
- 更新前会自动在「文档\SmartPlannerBackups」保存一份备份，保留最近 3 份
- 升级前也可以在「设置 → 存储」手动导出备份

## 更新

- 设置页和托盘菜单都可以检查更新
- 新版本在后台下载，完成后提示重启安装
- 从 0.6.2 升级到 0.6.3 可自动更新，数据保存在独立目录，不会随安装目录被删除
- 首次从 0.2.0 升级到 0.3.0 需要手动安装一次；之后版本可自动更新

## 构建

```bash
npm run build       # 编译并检查类型
npm run build:win   # 生成 Windows 安装包
npm run release:win # 构建并发布到 GitHub Releases（需要 GH_TOKEN）
```

也可以推送 `v*` 标签，由 `.github/workflows/release.yml` 在 Windows 上自动构建并发布。
发布时请确保 tag 版本与 `package.json` 的 `version` 一致。
